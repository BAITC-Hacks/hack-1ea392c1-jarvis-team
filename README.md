# Классификатор обращений

Маленький скрипт, который разбирает 5 готовых обращений: определяет
категорию (**справка** / **жалоба** / **другое**) и печатает черновик
ответа на русском для каждого.

## Как запустить

```bash
python3 classify.py
```

Требования: Python 3.8+, никаких сторонних библиотек не нужно.

Скрипт читает `messages.txt` (одно обращение на строку) из той же папки
и построчно печатает результат: текст обращения → категория → черновик
ответа.

## Что получилось

- Классификация — через ключевые слова (простые правила), без вызова
  LLM и без API-ключей, чтобы решение работало «из коробки» и
  воспроизводимо.
- Для каждой категории — свой шаблон черновика ответа на русском
  (справка → куда обратиться и сроки; жалоба → извинения + эскалация;
  другое → уточняющий вопрос).
- В `classify.py` оставлена закомментированная функция
  `classify_with_llm`, показывающая, как заменить правила на один
  вызов LLM (Claude) — при необходимости переключить classify() на неё
  дело нескольких строк.
